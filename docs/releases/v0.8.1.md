## Updating

Replace the installed package using its **current filename**, rescan plugins,
and reload the settings page. Settings, grants and cached results are preserved.

If upgrading from the original Release Radar installation, keep the filename
`release-radar.ndp` to retain its existing plugin ID and storage. Do not install
both filenames. New installations use `navidrome-upcoming-releases-plugin.ndp`.

The release includes the installable plugin, reviewed source archive and SHA256SUMS.
