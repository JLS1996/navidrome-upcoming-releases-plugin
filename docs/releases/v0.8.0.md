## Installation

Download `navidrome-upcoming-releases-plugin.ndp`, copy it to Navidrome's plugins
folder and rescan plugins. Grant one user and the intended libraries. Reports stay
in private plugin storage; the plugin adds no web server or public download route.

## Upgrading from Release Radar

Navidrome identifies a plugin by its filename. To preserve your existing settings,
permissions, cache and notification history, **rename the download to
`release-radar.ndp` before replacing the old package**, then rescan plugins.
The manifest name updates; storage remains under the original plugin ID.

Do not install both filenames. They would run as separate plugins. Keep the same
calendar instance name to preserve existing event identities.

**Enable the new ntfy switch after upgrading if you want alerts.** It defaults to
off even when a topic is already saved. Release-day reminders also default to off.
They use UTC and require a confirmed full date and the plugin running on that day.
